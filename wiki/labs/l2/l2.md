# Lab 2 - Postman API tests

**Course:** Software Quality Engineering 3  
**Team:** Group 4  
**Application:** GitLab REST API v4  
**Source lab:** [Lab 1](../l1/l1.md)

## Scope

Lab 2 implements the individual API test design from Lab 1 in Postman. The
collection uses environment and collection variables, reusable test data,
request assertions and cleanup requests without storing credentials in Git.

## Individual implementations

### Alexis Frene — Project labels

- [Alexis's Lab 2 document](l2_alexis.md)
- [Postman collection and environment](postman/alexis-lab2/README.md)

The implementation is based on the 17 Project labels LLTC cases defined in
[Lab 1](../l1/l1_alexis.md#actividad-4). It covers positive, negative,
authentication/authorization, boundary and E2E scenarios.

### Yeraldin Vasquez — Project issues

- [Yeraldin's Lab 2 document](l2_yeraldin.md)
- [Postman collection and environment](postman/yeraldin-lab2/README.md)

The implementation is based on the 15 Project issues LLTC cases defined in
[Lab 1](../l1/l1_yeraldin.md#actividad-4). It covers creation, retrieval, updates,
state transitions, closed filters, boundary pagination, Owner deletion,
unauthorized roles and complete E2E defect lifecycle.

## Team scope

This branch contains the individual Lab 2 implementations for Alexis Frene and
Yeraldin Vasquez. Individual documents detail the 5 activities, including peer
reviews and cross-evaluations. Repositories and Wikis modules are to be linked
as remaining team members deliver their respective Postman collections.
